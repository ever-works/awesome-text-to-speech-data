## Overview

Brainiall TTS MCP is a hosted neural text-to-speech integration packaged as an MCP (Model Context Protocol) server with OpenAPI examples. It provides developers with programmatic access to TTS synthesis capabilities.

## Features

- 54 voices across nine languages
- Brazilian Portuguese language support
- MCP server integration
- OpenAPI examples for REST API access
- Hosted neural TTS infrastructure

## Deployment

Cloud-hosted with self-hostable MCP server option.
