## Overview

eSpeak is an open-source text-to-speech synthesizer developed by Jonathan Duddington.

## Technical Details

- **First public release date**: 2006, February 10
- **Latest stable version**: 2022, April 3
- **License**: GPLv3+
- **Available languages**: Afrikaans, Albanian, Armenian, Cantonese, Catalan, Croatian, Czech, Danish, Dutch, English (British, US, Scottish, Westindies...), Esperanto, Estonian, Finnish, French (France, Belgium), Georgian, German, Greek, Hindi, Hungarian, Icelandic, Indonesian, Italian, Kannada, Kurdish, Latvian, Lojban, Macedonian, Malayalam, Mandarin, Norwegian, Persian, Polish, Portuguese, Romanian, Russian, Serbian, Slovak, Spanish, Swahili, Swedish, Tamil, Turkish, Vietnamese, Welsh
- **Available voices**: several
- **Programming language**: C++
- **Operating system(s)**: Linux, Windows, Mac OS X, RISC OS

## Technical Voice Details

- SSML support: Yes
- SAPI version: 5.x
- CLI support: Yes
