## Overview

Microsoft Speech API (SAPI) is Microsoft's text-to-speech voice system bundled with Windows.

## Technical Details

- **First public release date**: 1995
- **Latest stable version**: 2012
- **License**: Bundled with Windows (Proprietary)
- **Operating system(s)**: Microsoft Windows

## Technical Voice Details

- SSML support: 5.x only
- SAPI version: 4.x/5.x
