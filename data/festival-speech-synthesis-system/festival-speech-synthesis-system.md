## Overview

Festival Speech Synthesis System is an open-source text-to-speech system developed by CSTR at the University of Edinburgh.

## Technical Details

- **First public release date**: Unknown
- **Latest stable version**: 2014, December
- **License**: MIT-like license
- **Available languages**: English (UK), English (US), Spanish, Hindi, Croatian, Finnish, Polish, Welsh
- **Available voices**: Several
- **Programming language**: C++
- **Operating system(s)**: Linux, Windows
